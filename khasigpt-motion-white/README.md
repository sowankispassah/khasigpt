# KhasiGPT — White Motion

A separate 62.1-second vertical promo with a white canvas, kinetic typography, camera moves into the language picker, fast streamed responses, product card reveals, scrolling plans, and a download end card.

## Preview and export

```sh
npm install
npm run dev
npm run render
```

Studio runs at `http://localhost:3002/KhasiGPTWhiteMotion`. Export: `out/KhasiGPT-white-motion.mp4` (1080 × 1920, 30 fps). `npm run lint` checks the source and TypeScript.

Each scene is a separate composition in Studio and a separate file in `src/scenes/`. Copy lives in `src/content.ts`. All assets and fonts are local; this project does not import code or runtime assets from either earlier promo project.

## Audio and assets

The electronic score is original and generated by `scripts/make_score.py` (Python + NumPy). UI click, switch, and whoosh samples come from the Remotion sound-effects library at `https://remotion.media/`. The KhasiGPT and Google Play artwork, shopping imagery, and product/news copy were supplied in the original brief. Inter is distributed under the SIL Open Font License (see `public/fonts/OFL.txt`).

The long news and shopping copy is promotional reference content supplied by the user, not a live feed.
